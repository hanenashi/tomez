tomez / Android

A plain text editor for Android.

Open a text file, read it, make changes, and save it. tomez works with one document at a time. It has a few fonts, four themes, and a text-size control.

Android 8.0 or later · UTF-8 · Files up to 1 MiB

This is a debug build for testing. Release notes. There is no Google Play listing yet.

TL;DR

  1. Open the ⋮ menu → Open and pick a file.
  2. Swipe to scroll. Tap the pencil to show or hide the keyboard.
  3. Use ⋮ → Text size to preview a different size as you move the slider.
  4. Choose ⋮ → Save to write your changes to the file.

The dot next to the filename means there are unsaved changes. A recovery draft is kept on the device, but you still need to Save.

01 / Read

Scroll without opening the keyboard.

Swipe up or down through the document. A flick keeps it moving after you lift your finger. Tap the icon between the pencil and ⋮ to toggle line wrapping. With wrapping off, swipe sideways to read long lines.

02 / Edit

Use the pencil when you want to type.

Tapping the text places the cursor. The pencil opens the keyboard at that position; tapping it again hides the keyboard. Hold a word to select it, then drag the handles. Android’s copy and paste controls are available.

03 / Appearance

Adjust the text while you read.

Open ⋮ for Font, Text size, Theme and Fullscreen. The size slider previews changes in the document behind the dialog. Apply keeps the new size; Cancel restores the previous size. You can also type a size into the number field.

Tap a screenshot to open it at full size. Images are from earlier device checks.

File commands

New
Starts a blank Untitled document and opens the keyboard.
Open
Uses Android’s document picker to choose a file.
Save
Writes to the current file. For an Untitled document, asks where to save it.
Save As
Asks for a name and location. The saved copy becomes the current document.
Close
Returns to a blank Untitled document with the keyboard hidden.

New, Open and Close ask what to do if you have unsaved changes.

A few limits

tomez edits UTF-8 plain text, including files with a UTF-8 byte-order mark. Markdown files open as text; there is no rendered preview. Files larger than 1 MiB and other text encodings are not supported. The app does not detect edits made to the same file by another app.

Fonts: system sans, system serif and monospace. Themes: Light, Dark, Grey and Green. These settings change how text is displayed; they do not add formatting to the file.

Editor prostého textu pro Android.

Otevři textový soubor, přečti ho, uprav a ulož. tomez pracuje vždy s jedním dokumentem. Nabízí několik písem, čtyři motivy a nastavení velikosti textu.

Ve zkratce

  1. Otevři nabídku ⋮ → Open a vyber soubor.
  2. Tažením posouvej text. Tužkou zobrazíš nebo skryješ klávesnici.
  3. V ⋮ → Text size měň velikost posuvníkem a sleduj náhled v dokumentu.
  4. Přes ⋮ → Save ulož změny do souboru.

Tečka vedle názvu souboru znamená neuložené změny. Aplikace ukládá místní koncept pro obnovení, ale soubor je pořád potřeba uložit přes Save.

01 / Čtení

Posouvej text bez otevírání klávesnice.

Tažením nahoru nebo dolů se posouváš v dokumentu. Po rychlém švihnutí posun ještě pokračuje. Ikona mezi tužkou a ⋮ zapíná a vypíná zalamování řádků. Když je vypnuté, dlouhé řádky můžeš posouvat do stran.

02 / Úpravy

Když chceš psát, klepni na tužku.

Klepnutí do textu umístí kurzor. Tužka otevře klávesnici na této pozici; další klepnutí ji skryje. Podržením slova ho vybereš a úchyty upravíš rozsah výběru. Kopírování a vkládání funguje přes běžnou nabídku Androidu.

03 / Vzhled

Uprav si zobrazení při čtení.

V nabídce ⋮ najdeš Font, Text size, Theme a Fullscreen. Posuvník velikosti mění náhled textu za dialogem. Apply novou velikost potvrdí, Cancel vrátí původní. Velikost můžeš také zadat číslem.

Klepnutím otevřeš snímek v plné velikosti. Snímky pocházejí z dřívějšího testování na telefonu.

Práce se soubory

New
Vytvoří prázdný dokument Untitled a otevře klávesnici.
Open
Otevře systémový výběr souborů Androidu.
Save
Uloží aktuální soubor. U dokumentu Untitled se zeptá na umístění.
Save As
Zeptá se na název a umístění. Uložená kopie se stane aktuálním dokumentem.
Close
Vrátí se k prázdnému dokumentu Untitled se skrytou klávesnicí.

Pokud máš neuložené změny, New, Open a Close se nejdřív zeptají, co s nimi.

Omezení

tomez upravuje prostý text v UTF-8, včetně souborů se značkou BOM. Markdown otevírá jako text, bez vykresleného náhledu. Soubory větší než 1 MiB a jiná kódování nejsou podporována. Aplikace nerozpozná změny, které ve stejném souboru provede jiná aplikace.

Písma: systémové bezpatkové, patkové a monospace. Motivy: Light, Dark, Grey a Green. Nastavení mění jen zobrazení textu, ne formátování souboru.
