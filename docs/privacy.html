Privacy

Last updated: 28 September 2026

tomez is designed as a local plaintext editor. The Android app does not include advertising, analytics, user accounts, telemetry, or its own network functionality.

Files

Files are opened and saved through Android's system document picker. tomez only accesses documents that you choose. Where supported, Android may grant the app persistent access to a selected document so it can be saved again later.

Recovery draft

When a document has unsaved changes, tomez may store a recovery draft in the app's private local storage. This draft is used only for restoring unsaved work and is removed after a successful save or explicit discard.

Data collection

tomez does not collect, transmit, sell, or share personal data.

This website

This website is hosted with GitHub Pages. Standard web request information may therefore be processed by GitHub according to GitHub's own policies. This is separate from the tomez Android app. The site stores your language choice in your browser.

Contact

Questions or bug reports can be filed on the tomez GitHub repository.

Soukromí

Poslední aktualizace: 28. září 2026

tomez je navržen jako lokální editor prostého textu. Aplikace pro Android neobsahuje reklamy, analytiku, uživatelské účty, telemetrii ani vlastní síťové funkce.

Soubory

Soubory se otevírají a ukládají přes systémový výběr dokumentů Androidu. tomez přistupuje pouze k dokumentům, které sami vyberete. Pokud to Android a poskytovatel souboru dovolí, může aplikace získat trvalé oprávnění k vybranému dokumentu, aby jej bylo možné později znovu uložit.

Záchranný koncept

Pokud dokument obsahuje neuložené změny, tomez může uložit záchranný koncept do soukromého lokálního úložiště aplikace. Slouží pouze k obnovení neuložené práce a po úspěšném uložení nebo výslovném zahození změn se odstraní.

Sběr dat

tomez neshromažďuje, neodesílá, neprodává ani nesdílí osobní údaje.

Tento web

Tento web je hostován pomocí GitHub Pages. GitHub proto může zpracovávat běžné údaje webových požadavků podle vlastních pravidel. To je oddělené od aplikace tomez pro Android. Web si v prohlížeči pamatuje zvolený jazyk.

Kontakt

Dotazy a hlášení chyb lze posílat přes repozitář tomez na GitHubu.
